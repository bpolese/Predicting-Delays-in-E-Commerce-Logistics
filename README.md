# E-Commerce Delivery Performance Analytics

This Streamlit app analyzes e-commerce delivery performance using customer, order, order item, and seller data.

## Business Problem

The app helps an e-commerce decision maker identify late-delivery risk, operational bottlenecks, seller performance issues, and geographic delivery patterns.

## Files Used

- customers_dataset.csv
- orders_dataset.csv
- order_items_dataset.csv
- sellers_dataset.csv

## How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
